# JuniorAGI_SDK

**Sovereign Edge-Native AGI Layer**

JuniorAGI_SDK provides persistent spectral TDA manifolds and structured memory for autonomous agents, built on MLX-native Apple Silicon with BitNet b1.58 ternary kernels.

It serves as the long-term memory and reasoning substrate for the JuniorCloud LLC sovereign edge ecosystem.

## Role in the Ecosystem

| Component       | Relationship to JuniorAGI_SDK                  |
|-----------------|------------------------------------------------|
| **JuniorStock** | Uses AGI memory for long-horizon decision making |
| **BitNet-mlx**  | Consumes structured memory states for reasoning  |
| **crispy-mouse**| Can persist macro execution history into memory  |
| **JuniorHome**  | Central orchestration hub that includes AGI layer|
| **JuniorMemSys**| Complementary topological memory system          |

## Current Capabilities

- MLX-native multi-threading on Apple Silicon
- BitNet b1.58 ternary weight support
- Spectral TDA manifold construction and persistence
- Low-rank FP16 residual connections
- Designed for integration with deterministic execution layers

## Philosophy

Build AGI that is:
- **Sovereign** by default (fully local)
- **Mathematically grounded** (TDA + linear algebra first)
- **Edge-efficient** (optimized for M-series and low-power devices)
- **Composable** with the rest of the JuniorCloud stack

## Integration Path

JuniorAGI_SDK is intended to be consumed by higher-level orchestrators (JuniorStock, JuniorHome) and can feed memory-augmented state into BitNet-mlx reasoning pipelines.

Part of the broader JuniorCloud LLC effort to build a complete sovereign edge technology stack.
