# MemSys Suite (Modern Second Brain)

Modern, production-grade memory system for the Junior ecosystem.

## Features
- Persistent contextual memory
- Hierarchical memory (short-term, long-term, episodic)
- Topological Data Analysis (TDA) ready
- Integration with Layer 2 Contextual Brain
- Cross-repo consumption (JuniorHome, JuniorPiPython, JuniorSOL, etc.)

Designed to be the shared memory layer across all 20+ repos.
